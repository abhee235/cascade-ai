# Operations manual 3: archival



## archival procedure 1

Before starting archival run 1, confirm the previous cycle closed cleanly and the on-call rotation has
acknowledged the hand-off. The reviewing operator files a summary under case 3001; disputes go to the
weekly sync. Retain the working notes for ninety days, then archive them with the archival ledger.
