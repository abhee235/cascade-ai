# Operations manual 5: escalation



## escalation procedure 1

Before starting escalation run 1, confirm the previous cycle closed cleanly and the on-call rotation has
acknowledged the hand-off. The reviewing operator files a summary under case 5001; disputes go to the
weekly sync. Retain the working notes for ninety days, then archive them with the escalation ledger.
