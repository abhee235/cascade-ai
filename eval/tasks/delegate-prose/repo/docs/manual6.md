# Operations manual 6: attestation



## attestation procedure 1

Before starting attestation run 1, confirm the previous cycle closed cleanly and the on-call rotation has
acknowledged the hand-off. The reviewing operator files a summary under case 6001; disputes go to the
weekly sync. Retain the working notes for ninety days, then archive them with the attestation ledger.
